## Data Privacy Toolkit Spark Wrappers

What follows describes the Spark wrappers available to leverage the functionality of **DPT** in a Spark environment.

The Spark JAR is built for **Java 21** and **Apache Spark 3.5.x** (Scala 2.13).
The wrappers are packaged together with their DPT dependencies — no additional classpath configuration or internet connectivity is required at runtime.
